# Security Policy (VDP)

## Supported Versions
We provide security maintenance for the following versions:

| Version | Supported |
| :--- | :--- |
| v2.x | ✅ Active Support |
| v1.5.x | ⚠️ Critical Patches Only |
| < v1.5 | ❌ End of Life |

## Reporting a Vulnerability
Technical resilience is the cornerstone of Winterhold Core. If you discover a security vulnerability, please follow the process below:

1. **Do not open a public Issue.**
2. Submit a detailed report to `security@example.com` (using PGP encryption where possible).
3. Include reproduction steps, potential impact, and a proposed fix if available.

### Responsible Disclosure Commitment
* We will acknowledge receipt of your report within 24 business hours.
* We will provide regular updates regarding the remediation progress.
* We will credit the researcher in the security advisory upon the release of the patch (unless anonymity is requested).
